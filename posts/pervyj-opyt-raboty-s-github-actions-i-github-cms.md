Когда мне захотелось выложить запись о всём насущном именно на сайт, чтоб в последствии этот нелёгкий путь мог видеть работодатель или клиент, сразу в голову пришёл вопрос: вот есть записи, сделанные статично, для примера, но ведь нельзя каждый раз лезть в html, добавлять там что-то новое и пушить бесконечно на Git это же кошмар, как создать какую-то минимальную админку для блога без особых изменений самой структуры? Я попробовала погуглить, обратилась к ИИ и он предложил мне то, о чем ранее я не знала. Pages CMS. Минимальная админка для того, чтобы клепать посты. Повозишись чуть-чуть с настройкой и минимально отредактировав файлы для страницы с постами, под вечер у меня получилась вполне себе. Самое интересное, можно сделать абсолютно любой конфиг для CMS, самый разный, остается только повозиться с js и минимально добавить стили. Что-то буду оставлять здесь. В идеале, хочу каждый день вносить заметки о том,что было сделано и что в планах сделать. Радует то, что выходной прошел не зря. Сделана настройка CMS для сайта, также прослушано 7 уроков по Frontend разработке и вскоре там пойдет практика. Кстати, для практики у меня уже есть идеи как можно будет прокачивать знания. К примеру, когда пойдут уроки по всяким селекторам и атрибутам, можно будет дополнительно гуглить всякие фишки и хаки, относящиеся к ним, после упражняться, мб писать что-то маленькое незначительное и публиковать, может хоть так люди поймут,что я что-то знаю учусь. Также на вечер у меня запланированы уроки по Девопсу, думаю, всё успею. А, ну и два потраченных часа в спортзале тоже принесли дозу дофамина. Беру от выходных всё,чтобы уволиться с завода. Надеюсь, у меня получится
